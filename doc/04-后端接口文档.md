# 后端接口文档

## 1. 基础信息

后端基于 FastAPI，默认服务地址：

```text
http://localhost:8000
```

业务 API 默认前缀：

```text
/api
```

自动接口文档：

```text
http://localhost:8000/docs
```

## 2. 健康检查

### `GET /health`

检查后端服务是否可用。

响应示例：

```json
{
  "status": "ok",
  "env": "local"
}
```

## 3. 风格预设接口

### `GET /api/style-presets`

查询启用中的风格预设。

Query：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `preset_type` | string | 否 | `image` 或 `copy` |

### `GET /api/style-presets/defaults`

查询系统默认风格预设。

### `POST /api/style-presets`

创建风格预设。

请求体：

```json
{
  "preset_type": "copy",
  "name": "真实吐槽测评风",
  "description": "像普通用户真实记录，不写广告腔",
  "prompt_template": "基于真实体验生成小红书笔记",
  "default_params": {
    "title_count": 5,
    "tone": "真实直观"
  },
  "is_system_default": false,
  "is_active": true
}
```

### `GET /api/style-presets/{preset_id}`

查询单个风格预设。

### `PATCH /api/style-presets/{preset_id}`

更新风格预设。当前实现使用完整 `StylePresetCreate` 请求体。

### `DELETE /api/style-presets/{preset_id}`

软删除风格预设，将 `is_active` 改为 `false`。

## 4. 帖子接口

### `POST /api/posts`

创建帖子草稿，可同时创建多个产品卡片。

请求体：

```json
{
  "image_style_preset_id": "image-preset-id",
  "image_custom_prompt": null,
  "image_custom_params": {},
  "copy_style_preset_id": null,
  "copy_custom_prompt": "像真实朋友聊天，保留轻微吐槽，不要广告腔",
  "copy_custom_params": {},
  "products": [
    {
      "product_name": "Byt 气泡水",
      "price": 6.9,
      "user_impression": "包装好看，口感清爽，但是甜味有点明显",
      "sort_order": 0
    }
  ]
}
```

风格字段约定：

- 使用系统默认图片风格时传 `image_style_preset_id`。
- 使用自定义图片风格时传 `image_custom_prompt`。
- 使用系统默认文案风格时传 `copy_style_preset_id`。
- 使用自定义文案风格时传 `copy_custom_prompt`。

### `GET /api/posts`

查询帖子列表。

Query：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `status` | string | 否 | `draft`、`published`、`analyzed` |

### `GET /api/posts/{post_id}`

查询帖子详情，返回帖子、产品、图片。

### `PATCH /api/posts/{post_id}`

更新帖子文案字段。

请求体示例：

```json
{
  "selected_title": "Byt 这几款小零食，我真实测完有点意外",
  "content": "正文内容",
  "cover_text": "Byt真实测评\n值不值得买",
  "tags": ["Byt测评", "真实测评"],
  "comment_guide": "你还想看哪款？"
}
```

### `DELETE /api/posts/{post_id}`

删除帖子。ORM 关系会级联删除关联产品、指标、提醒。

### `POST /api/posts/{post_id}/generate-copy`

生成帖子文案并写回数据库。

写回字段：

- `posts.selected_title`
- `posts.title_options`
- `posts.content`
- `posts.cover_text`
- `posts.tags`
- `posts.comment_guide`
- `posts.recommendation_level`
- `products.agent_summary`
- `products.agent_recommendation`
- `products.agent_detail`

### `POST /api/posts/{post_id}/regenerate-copy`

重新生成文案。当前实现等同于 `generate-copy`。

### `POST /api/posts/{post_id}/mark-published`

标记帖子已发布。

行为：

- `status = published`
- `published_at = now`
- 创建一条 `metrics_input` 提醒
- 提醒时间为当前时间 + `REMINDER_DAYS_AFTER_PUBLISH`

### `POST /api/posts/{post_id}/mark-analyzed`

手动标记帖子已分析。

行为：

- `status = analyzed`
- `analyzed_at = now`

## 5. 产品接口

### `POST /api/posts/{post_id}/products`

为帖子新增产品。

请求体：

```json
{
  "product_name": "Byt 饼干",
  "price": 9.9,
  "user_impression": "入口很香，但后面有点腻，性价比一般",
  "sort_order": 1
}
```

### `GET /api/posts/{post_id}/products`

查询帖子下产品列表。

### `GET /api/products/{product_id}`

查询产品详情，包含图片列表。

### `PATCH /api/products/{product_id}`

更新产品。

支持字段：

```json
{
  "product_name": "新名称",
  "price": 12.9,
  "user_impression": "更新后的真实感受",
  "sort_order": 0
}
```

### `DELETE /api/products/{product_id}`

删除产品。

## 6. 图片接口

### `POST /api/products/{product_id}/images`

上传产品图片。

Content-Type：

```text
multipart/form-data
```

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `file` | file | 图片文件 |

行为：

- 调用 `StorageService.save_upload`
- 本地存储时写入 `LOCAL_STORAGE_DIR`
- 创建 `card_images` 记录
- 默认 `image_type = original`

### `GET /api/products/{product_id}/images`

查询产品图片列表。

### `GET /api/images/{image_id}`

查询单张图片。

### `PATCH /api/images/{image_id}`

更新图片排序、选择状态、AI 描述等。

请求体：

```json
{
  "sort_order": 0,
  "final_sort_order": 1,
  "is_selected_for_post": true,
  "ai_description": "主体清晰，适合作为封面"
}
```

### `DELETE /api/images/{image_id}`

软删除图片。

行为：

- `is_deleted = true`
- `deleted_at = now`

### `POST /api/images/{image_id}/process`

创建图片处理结果。

当前实现：

- 保留原图 URL 作为处理图结果。
- 创建 `image_processing_jobs` 记录。
- 将帖子上的 `image_custom_prompt` 写入处理任务上下文。
- 创建 `image_type = processed` 的 `card_images` 记录。

后续接入真实图片生成服务时，应替换该接口内部处理逻辑。

## 7. 数据与分析接口

### `POST /api/posts/{post_id}/metrics`

录入帖子表现数据。

请求体：

```json
{
  "views": 1200,
  "likes": 86,
  "collects": 31,
  "comments": 12,
  "followers_gained": 8,
  "analyze": true
}
```

行为：

- 写入 `post_metrics`
- 自动计算互动率、收藏率、转粉率
- 当 `analyze = true` 时生成复盘，并将帖子状态改为 `analyzed`

### `GET /api/posts/{post_id}/metrics`

查询帖子历史指标记录。

### `POST /api/posts/{post_id}/analyze`

基于最新一条指标数据生成复盘。

### `GET /api/posts/{post_id}/analysis`

查询最新一条带复盘结果的指标记录。

## 8. 提醒接口

### `GET /api/reminders`

查询提醒列表。

Query：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `status` | string | 否 | `pending`、`done`、`ignored` |

### `GET /api/reminders/pending`

查询已到期且状态为 `pending` 的提醒。

### `PATCH /api/reminders/{reminder_id}`

更新提醒。

请求体：

```json
{
  "status": "pending",
  "message": "请录入数据"
}
```

### `POST /api/reminders/{reminder_id}/done`

标记提醒已完成。

### `POST /api/reminders/{reminder_id}/ignore`

忽略提醒。

## 9. 首页概览接口

### `GET /api/analytics/overview`

返回首页概览。

响应字段：

| 字段 | 说明 |
| --- | --- |
| `draft_count` | 草稿数 |
| `pending_metrics_count` | 已到期待录入数据提醒数 |
| `published_this_week_count` | 近 7 天已发布帖子数 |
| `average_interaction_rate` | 平均互动率 |
| `average_collect_rate` | 平均收藏率 |
| `best_post` | 当前互动率最高的帖子摘要 |
| `next_suggestion` | 下一期建议 |
