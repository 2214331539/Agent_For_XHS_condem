# 运维问题与扩展规划

## 1. 常见问题

### 1.1 PostgreSQL 密码校验失败

错误示例：

```text
psycopg.OperationalError: password authentication failed for user "byt"
```

常见原因：

- 本机已有 PostgreSQL 占用 `5432`。
- 后端连接到了本机 PostgreSQL，而不是项目 Docker PostgreSQL。
- `.env` 仍使用 `localhost:5432`。
- Docker 数据卷已经初始化过，后续修改 `POSTGRES_PASSWORD` 不会自动重置已有用户密码。

解决：

1. 确认项目使用 `55432`：

```env
DATABASE_URL=postgresql+psycopg://byt:byt_dev_password@localhost:55432/byt_review
```

2. 重建项目 PostgreSQL：

```powershell
docker compose up -d --force-recreate postgres
```

3. 检查端口：

```powershell
docker ps
```

应看到：

```text
0.0.0.0:55432->5432/tcp
```

### 1.2 8000 端口被占用

检查：

```powershell
Get-NetTCPConnection -LocalPort 8000
```

停止占用进程：

```powershell
Stop-Process -Id <PID> -Force
```

### 1.3 前端无法访问后端

检查：

- 后端是否启动在 `http://127.0.0.1:8000`。
- 前端 `VITE_API_BASE_URL` 是否为 `http://localhost:8000/api`。
- 后端 CORS 是否包含 `http://localhost:5173`。
- 浏览器控制台是否有跨域或网络错误。

### 1.4 上传图片后无法显示

检查：

- `LOCAL_STORAGE_DIR` 是否存在并可写。
- `PUBLIC_MEDIA_BASE_URL` 是否指向后端。
- 后端是否挂载 `/media`。
- 图片 URL 是否能在浏览器直接打开。

### 1.5 Docker 数据不是最新

如果修改了 `docker-compose.yml` 或镜像内容：

```powershell
docker compose up -d --build --force-recreate
```

如果需要清空数据库：

```powershell
docker compose down -v
docker compose up -d postgres
```

## 2. 当前限制

### 2.1 Agent

当前 Agent 是本地规则实现，不是真实 LLM 调用。

限制：

- 生成质量依赖规则，不具备真实模型的理解能力。
- 图片理解和图片生成没有真正调用模型。
- 分析结果是基于简单阈值逻辑。

### 2.2 图片处理

当前图片处理接口会：

- 创建处理任务。
- 保留原图 URL 作为处理图结果。
- 将自定义图片风格写入任务上下文。

尚未完成：

- 图片理解。
- 图片编辑/生成。
- 处理失败重试。
- 图片尺寸读取。

### 2.3 存储

当前可用的是本地存储。

阿里云 OSS 配置已预留，但 SDK 上传逻辑未实现。

### 2.4 数据库迁移

当前通过 `Base.metadata.create_all` 自动建表。生产环境应引入 Alembic。

### 2.5 前端架构

当前前端所有页面集中在 `App.tsx`，适合 MVP，但后续维护建议拆分。

### 2.6 安全

当前没有实现：

- 登录
- 用户体系
- 权限控制
- API 鉴权
- 文件上传安全扫描

## 3. 后续扩展规划

### 3.1 接入 OpenAI Responses API

建议拆分 Agent Provider：

```text
AgentService
  ├── LocalAgentProvider
  └── OpenAIAgentProvider
```

优先接入：

- 文案生成结构化输出。
- 数据复盘结构化输出。
- 图片理解。

### 3.2 接入图片生成/编辑

建议流程：

```text
上传原图
  -> ImageUnderstandingAgent
  -> ImageStyleAgent
  -> 保存处理图
  -> 创建 image_processing_jobs
```

需要补充：

- 图片尺寸读取。
- 任务状态机。
- 失败重试。
- 处理结果审核。

### 3.3 接入阿里云 OSS

需要实现：

- OSS Client 初始化。
- 文件上传。
- object key 规范。
- 公开 URL 或签名 URL。
- 删除对象。
- 文件大小和 MIME 校验。

### 3.4 引入 Alembic

建议步骤：

1. 初始化 Alembic。
2. 生成当前模型基线迁移。
3. 禁止生产环境自动 `create_all`。
4. 部署时执行迁移。

### 3.5 前端拆分

建议目录：

```text
src/
├── pages/
│   ├── DashboardPage.tsx
│   ├── CreatePostPage.tsx
│   ├── PostsPage.tsx
│   ├── PostDetailPage.tsx
│   ├── MetricsPage.tsx
│   └── AnalysisPage.tsx
├── components/
├── api/
├── config/
└── types/
```

后续如果需要多人使用，应补充：
