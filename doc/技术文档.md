## 当前关键约定

- 数据库使用 PostgreSQL。
- 本地开发默认连接 `localhost:55432`，避免和本机已有 PostgreSQL 的 `5432` 冲突。
- 后端 API 前缀为 `/api`。
- 前端默认 API 地址为 `http://localhost:8000/api`。
- 图片默认使用本地 `media` 目录存储，通过后端 `/media` 暴露。
- Agent 当前为本地规则实现，接口已为后续 OpenAI Responses API 接入预留配置。
