# 技术选型与配置管理

## 1. 前端技术选型

| 技术 | 用途 |
| --- | --- |
| React | 构建管理后台单页应用 |
| Vite | 开发服务器和生产构建 |
| TypeScript | 类型约束 |
| Ant Design | 后台表单、表格、卡片、Tabs、弹窗等组件 |
| CSS | 页面布局、极简视觉风格和响应式样式 |

前端入口：

- `frontend/src/main.tsx`
- `frontend/src/App.tsx`

前端配置：

- `frontend/src/config/appConfig.ts`

```ts
export const appConfig = {
  apiBaseUrl: import.meta.env.VITE_API_BASE_URL ?? "http://localhost:8000/api"
};
```

## 2. 后端技术选型

| 技术 | 用途 |
| --- | --- |
| FastAPI | HTTP API 服务 |
| Uvicorn | ASGI 运行服务 |
| SQLAlchemy 2.0 | ORM 和表结构定义 |
| Pydantic Settings | 环境变量配置管理 |
| PostgreSQL | 主数据库 |
| psycopg | PostgreSQL 驱动 |
| python-multipart | 图片上传表单解析 |

后端入口：

- `backend/app/main.py`

## 3. 数据库选型

数据库统一使用 PostgreSQL。

本地开发使用端口 `55432`：

```env
DATABASE_URL=postgresql+psycopg://byt:byt_dev_password@localhost:55432/byt_review
```

容器内后端连接数据库使用 Docker Compose 服务名：

```env
DATABASE_URL=postgresql+psycopg://byt:byt_dev_password@postgres:5432/byt_review
```

选择 PostgreSQL 的原因：

- 适合帖子、产品、指标等结构化数据。
- JSON 字段可存 Agent 结果和参数。
- 后续适合扩展数据分析、报表和多用户数据隔离。

## 4. 存储选型

当前默认使用本地存储：

- 上传文件保存到 `LOCAL_STORAGE_DIR`
- 后端通过 `/media` 静态路径暴露

相关配置：

```env
STORAGE_BACKEND=local
LOCAL_STORAGE_DIR=./media
PUBLIC_MEDIA_BASE_URL=http://localhost:8000/media
```

阿里云 OSS 已预留配置：

```env
OSS_ENDPOINT=
OSS_BUCKET=
OSS_ACCESS_KEY_ID=
OSS_ACCESS_KEY_SECRET=
OSS_REGION=
OSS_PUBLIC_BASE_URL=
```

当前 `backend/app/services/storage.py` 中的 `_save_aliyun_oss` 尚未实现。接入 OSS 时需要补充 SDK 上传、对象 key 生成、公开 URL 或签名 URL 逻辑。

## 5. Agent 设计

当前 Agent 服务位置：

```text
backend/app/services/agent.py
```

当前实现为本地规则逻辑，用于跑通业务闭环。配置项保留：

```env
AGENT_PROVIDER=local
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4.1-mini
OPENAI_IMAGE_MODEL=gpt-image-1
```

后续可扩展为：

- `local`: 本地规则生成。
- `openai`: 使用 OpenAI Responses API 生成结构化输出。

## 6. 风格配置

测评页面有两类风格：

- 图片处理风格
- 文案生成风格

每类风格都有两种输入方式：

1. 使用系统默认：选择 `agent_style_presets` 中的预设。
2. 自定义：用户输入自然语言风格。

对应字段：

| 字段 | 含义 |
| --- | --- |
| `image_style_preset_id` | 系统图片风格预设 ID |
| `image_custom_prompt` | 用户自定义图片处理自然语言风格 |
| `copy_style_preset_id` | 系统文案风格预设 ID |
| `copy_custom_prompt` | 用户自定义文案生成自然语言风格 |

## 7. 后端配置项

配置集中在：

```text
backend/app/core/config.py
```

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `APP_NAME` | `Byt Review System` | FastAPI 应用名称 |
| `APP_ENV` | `local` | 当前运行环境 |
| `API_PREFIX` | `/api` | API 前缀 |
| `BACKEND_CORS_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173` | CORS 白名单 |
| `DATABASE_URL` | `postgresql+psycopg://byt:byt_dev_password@localhost:55432/byt_review` | PostgreSQL 连接 |
| `OPENAI_API_KEY` | 空 | 后续 OpenAI 调用密钥 |
| `OPENAI_MODEL` | `gpt-4.1-mini` | 文案/分析模型 |
| `OPENAI_IMAGE_MODEL` | `gpt-image-1` | 图片模型 |
| `AGENT_PROVIDER` | `local` | Agent Provider |
| `STORAGE_BACKEND` | `local` | 存储后端 |
| `LOCAL_STORAGE_DIR` | `./media` | 本地上传目录 |
| `PUBLIC_MEDIA_BASE_URL` | `http://localhost:8000/media` | 图片访问根地址 |
| `REMINDER_DAYS_AFTER_PUBLISH` | `7` | 发布后提醒天数 |

## 8. 推荐 `.env`

```env
APP_NAME=Byt Review System
APP_ENV=local
API_PREFIX=/api
BACKEND_CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173

DATABASE_URL=postgresql+psycopg://byt:byt_dev_password@localhost:55432/byt_review

OPENAI_API_KEY=
OPENAI_MODEL=gpt-4.1-mini
OPENAI_IMAGE_MODEL=gpt-image-1
AGENT_PROVIDER=local

STORAGE_BACKEND=local
LOCAL_STORAGE_DIR=./media
PUBLIC_MEDIA_BASE_URL=http://localhost:8000/media

REMINDER_DAYS_AFTER_PUBLISH=7

VITE_API_BASE_URL=http://localhost:8000/api
```
