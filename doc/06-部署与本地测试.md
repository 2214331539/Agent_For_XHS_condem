# 部署与本地测试

## 1. 环境要求

推荐环境：

- Python 3.12+
- Node.js 20+
- npm
- Docker Desktop
- Windows PowerShell

## 2. 初始化配置

在项目根目录复制配置：

```powershell
Copy-Item .env.example .env
```

确认 `.env` 中数据库连接为：

```env
DATABASE_URL=postgresql+psycopg://byt:byt_dev_password@localhost:55432/byt_review
```

## 3. 启动 PostgreSQL

```powershell
docker compose up -d postgres
```

查看容器：

```powershell
docker ps
```

应看到端口映射：

```text
0.0.0.0:55432->5432/tcp
```

验证数据库连接：

```powershell
python -c "import psycopg; conn=psycopg.connect('postgresql://byt:byt_dev_password@127.0.0.1:55432/byt_review'); print(conn.execute('select current_user, current_database()').fetchone()); conn.close()"
```

预期输出：

```text
('byt', 'byt_review')
```

## 4. 启动后端

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

访问：

```text
http://127.0.0.1:8000/health
http://127.0.0.1:8000/docs
```

健康检查预期：

```json
{
  "status": "ok",
  "env": "local"
}
```

## 5. 启动前端

另开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

访问：

```text
http://127.0.0.1:5173
```

## 6. 构建与基础验证

后端语法检查：

```powershell
python -m compileall backend\app
```

前端生产构建：

```powershell
cd frontend
npm run build
```

说明：前端构建可能出现 Vite chunk size warning，主要来自 Ant Design 依赖体积。这是性能提示，不是构建失败。

## 7. 完整 Docker Compose 启动

根目录执行：

```powershell
docker compose up -d --build
```

服务地址：

| 服务 | 地址 |
| --- | --- |
| Frontend | `http://localhost:5173` |
| Backend | `http://localhost:8000` |
| Backend Docs | `http://localhost:8000/docs` |
| PostgreSQL | `localhost:55432` |

## 8. Docker 服务说明

`docker-compose.yml` 包含：

- `postgres`: PostgreSQL 16
- `backend`: FastAPI 服务
- `frontend`: Vite 前端服务

PostgreSQL 数据卷：

```text
postgres_data:/var/lib/postgresql/data
```

后端媒体目录挂载：

```text
./media:/app/media
```

## 9. 重置本地数据库

如需删除全部本地数据库数据：

```powershell
docker compose down -v
docker compose up -d postgres
```

注意：`down -v` 会删除 PostgreSQL 数据卷，所有本地数据会丢失。

## 10. 手动业务测试流程

1. 打开前端 `http://127.0.0.1:5173`。
2. 进入“新建测评”。
3. 选择图片处理风格和文案生成风格。
4. 新增产品卡片，填写产品名称、价格、真实感受。
5. 上传图片。
6. 点击“生成完整帖子”。
7. 进入草稿详情，检查标题、正文、标签。
8. 点击“我已发布”。
9. 在内容管理中进入数据录入。
10. 输入浏览、点赞、收藏、评论、涨粉。
11. 点击“保存并生成复盘”。
12. 查看复盘分析页。
