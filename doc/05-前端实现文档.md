# 前端实现文档

## 1. 前端目录

```text
frontend/
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.ts
└── src/
    ├── App.tsx
    ├── main.tsx
    ├── styles.css
    ├── types.ts
    ├── api/
    │   └── client.ts
    └── config/
        └── appConfig.ts
```

## 2. 应用入口

### `src/main.tsx`

负责：

- 创建 React Root。
- 配置 Ant Design 中文语言包。
- 配置 Ant Design 主题 token。
- 引入全局样式。

### `src/App.tsx`

当前前端主要页面和状态逻辑集中在 `App.tsx`。页面切换通过本地状态 `view` 完成。

页面枚举：

```ts
type View = "dashboard" | "create" | "posts" | "detail" | "metrics" | "analysis";
```

## 3. API 客户端

位置：

```text
frontend/src/api/client.ts
```

职责：

- 统一拼接 API 根地址。
- 统一处理 JSON 请求。
- 自动识别 `FormData` 上传请求。
- 请求失败时抛出错误。

API 根地址：

```ts
appConfig.apiBaseUrl
```

默认：

```text
http://localhost:8000/api
```

- 下一期提醒
- 最近帖子列表

### 5.2 新建测评

组件：

```text
CreatePost
```

核心输入：

- 图片处理风格
- 文案生成风格
- 产品卡片
- 图片文件

风格模式：

```ts
type StyleMode = "default" | "custom";
```

图片处理风格：

- `default`: 选择系统预设，提交 `image_style_preset_id`
- `custom`: 输入自然语言，提交 `image_custom_prompt`

文案生成风格：

- `default`: 选择系统预设，提交 `copy_style_preset_id`
- `custom`: 输入自然语言，提交 `copy_custom_prompt`

提交流程：

1. 校验至少一个产品有名称和真实感受。
2. 如果选择自定义风格，校验对应输入框非空。
3. 调用 `POST /api/posts` 创建帖子和产品。
4. 如果有图片，逐个调用 `POST /api/products/{product_id}/images`。
5. 调用 `POST /api/posts/{post_id}/generate-copy`。
6. 进入草稿详情页。

操作：

### 5.5 数据录入

组件：

```text
MetricsEntry
```

录入字段：

- 浏览量
- 点赞数
- 收藏数
- 评论数
- 涨粉数

前端实时计算：

```text
互动率 = (点赞 + 收藏 + 评论) / 浏览量
收藏率 = 收藏 / 浏览量
转粉率 = 涨粉 / 浏览量
```

提交：

- 保存数据：`analyze=false`
- 保存并生成复盘：`analyze=true`

### 5.6 复盘分析

组件：

```text
AnalysisView
```

接口：

- `GET /api/posts/{post_id}/analysis`

展示：

- 浏览量
- 互动率
- 收藏率
- 转粉率
- AI 复盘结论
- 标题建议
- 封面建议
- 下一期选题

## 6. 状态管理

当前没有引入 Redux、Zustand 或 React Router。主要状态在 `App` 中维护：

```ts
const [view, setView] = useState<View>("dashboard");
const [posts, setPosts] = useState<Post[]>([]);
const [overview, setOverview] = useState<Overview | null>(null);
const [stylePresets, setStylePresets] = useState<StylePreset[]>([]);
const [selectedPostId, setSelectedPostId] = useState<string | null>(null);
```

刷新数据统一通过：

```ts
async function refresh()
```

## 7. 样式规范

样式集中在：

```text
frontend/src/styles.css
```

主要设计约定：

- 温暖浅色背景。
- 卡片使用 `1px solid #eaeaea`。
- 弱阴影或无阴影。
- 标签使用低饱和色。
- 主按钮为黑底白字。
- 页面采用 sidebar + main panel 布局。
- 移动端改为单列布局。

## 8. 后续前端优化建议

- 引入 React Router，把页面状态迁移到 URL。
- 拆分 `App.tsx` 为多个页面和业务组件。
- 增加表单编辑保存能力。
- 给长页面增加加载态和错误态。
- 使用动态 import 优化 Ant Design 构建体积。
- 增加端到端测试。
