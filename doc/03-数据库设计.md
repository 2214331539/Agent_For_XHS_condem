# 数据库设计

## 1. 设计原则

数据库使用 PostgreSQL，ORM 使用 SQLAlchemy 2.0。当前应用启动时通过 `Base.metadata.create_all(bind=engine)` 自动创建表。

生产环境建议引入 Alembic，避免依赖自动建表进行结构变更。

## 2. 表关系概览

```text
posts
  ├── products
  │     └── card_images
  ├── post_metrics
  └── reminders

agent_style_presets
  ├── posts.image_style_preset_id
  ├── posts.copy_style_preset_id
  └── image_processing_jobs.style_preset_id

image_processing_jobs
  ├── posts
  ├── products
  ├── source card_images
  └── result card_images
```

## 3. `posts`

帖子主表，表示一期测评内容。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `String(36)` | UUID 主键 |
| `status` | `String(50)` | `draft`、`published`、`analyzed` |
| `selected_title` | `Text` | 最终标题 |
| `title_options` | `JSON` | 标题候选 |
| `content` | `Text` | 正文 |
| `cover_text` | `Text` | 封面文案 |
| `tags` | `JSON` | 标签列表 |
| `comment_guide` | `Text` | 评论引导语 |
| `recommendation_level` | `String(80)` | 整体种草/避雷程度 |
| `image_style_preset_id` | `String(36)` | 图片风格预设 |
| `image_custom_prompt` | `Text` | 自定义图片风格 |
| `image_custom_params` | `JSON` | 图片自定义参数 |
| `copy_style_preset_id` | `String(36)` | 文案风格预设 |
| `copy_custom_prompt` | `Text` | 自定义文案风格 |
| `copy_custom_params` | `JSON` | 文案自定义参数 |
| `published_at` | `DateTime` | 发布时间 |
| `analyzed_at` | `DateTime` | 分析完成时间 |
| `created_at` | `DateTime` | 创建时间 |
| `updated_at` | `DateTime` | 更新时间 |

索引：

- `status`

级联关系：

- 删除帖子会级联删除产品、指标、提醒。

## 7. `post_metrics`

帖子数据表现表。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `String(36)` | UUID 主键 |
| `post_id` | `String(36)` | 关联帖子 |
| `views` | `Integer` | 浏览量 |
| `likes` | `Integer` | 点赞数 |
| `collects` | `Integer` | 收藏数 |
| `comments` | `Integer` | 评论数 |
| `followers_gained` | `Integer` | 涨粉数 |
| `interaction_rate` | `Numeric(10,4)` | 互动率 |
| `collect_rate` | `Numeric(10,4)` | 收藏率 |
| `follower_rate` | `Numeric(10,4)` | 转粉率 |
| `analysis_result` | `Text` | 复盘文本 |
| `analysis_json` | `JSON` | 结构化复盘 |
| `recorded_at` | `DateTime` | 录入时间 |

指标公式：

```text
interaction_rate = (likes + collects + comments) / views
collect_rate = collects / views
follower_rate = followers_gained / views
```

当 `views <= 0` 时，比例均为 `0`。
